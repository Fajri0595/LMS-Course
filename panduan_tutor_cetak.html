Panduan Praktis Format Konten Interaktif untuk Tutor & Guru Awam (Metode Copy-Paste)

1. Konsep Utama: Metode Copy - Paste - Ganti Teks

Bapak/Ibu Tutor tidak perlu menguasai pemrograman untuk membuat materi interaktif. Cukup ikuti 3 langkah praktis:

  1. Pilih template kotak yang diinginkan dari buku panduan ini.
  2. Salin (Copy) kode HTML di dalam kotak hitam.
  3. Tempel (Paste) ke kolom "Isi Teks / Panduan Belajar / Narasi Modul" pada modal Edit Materi, lalu ganti teksnya dengan materi pelajaran Anda.

2. Kamus Tag Dasar

Kode HTML Fungsi Tampilan Contoh Hasil
<h3>Judul Modul</h3> Judul Pokok Bahasan Judul Modul
<p>Teks paragraf...</p> Paragraf bacaan normal Kalimat materi yang nyaman dibaca.
<strong>Teks Tebal</strong> Penekanan kata kunci Teks Tebal
<em>Teks Miring</em> Istilah asing / bahasa latin Teks Miring
